# ⚡ 電流急急棒（Buzz Wire）

沿著彎曲的光軌，把控制圈從**起點**移到**終點**，途中**碰到軌道邊緣就會觸電**——考驗你手有多穩！

🎮 **立即遊玩**：<https://prayer168.github.io/current-electrode-rod/>

---

## 玩法

1. 把游標／手指移到綠色起點 **▶** 並**按住**。
2. 沿著霓虹光軌前進，**不要碰到邊緣**。
3. 碰到邊緣會觸電，退回**最近的檢查點**（紫圈）重來。
4. 抵達金色終點 **⚑** 即過關，解鎖下一關。
5. 全 **12 關**難度遞增，挑戰你的最佳通關時間！

### 操作方式（支援電腦與手機）

| 裝置 | 操作 |
|------|------|
| 🖱️ 電腦 | 按住滑鼠左鍵沿光軌移動；放開或碰邊退回最近檢查點 |
| 📱 手機／平板 | 手指拖曳；**控制點在手指上方一點**，手指不會擋住視線 |

---

## 特色

- **12 關難度曲線**：軌道由寬到窄、由緩到彎，越後面越刺激
- **檢查點機制**：不必每次從頭來，手感更友善
- **計時與最佳紀錄**：每關獨立保存於瀏覽器（localStorage）
- **防作弊偵測**：快速移動會沿路徑取樣多點，無法跳過牆壁抄近路
- **Web Audio 音效**：觸電爆音、過檢查點提示音、過關上升音階（無外部檔案）
- **科技霓虹視覺**：觸電紅閃 + 金色火花粒子
- **RWD 響應式**：電腦、平板、手機皆可玩

## 技術

- 單一 `index.html`，純 HTML + CSS + JavaScript，**無任何外部相依**
- Canvas 2D 繪圖；碰撞用離屏遮罩（mask）逐像素判定

- 部署於 GitHub Pages
